# iPad 真机验收清单（M6）

自动测试覆盖不到的部分，需要在孩子用的那台 iPad 上亲手过一遍。每项打勾即可，有问题记在“备注”里。

## 0. 准备

- [ ] 代码已合并到 `main`，GitHub Actions 的 **Deploy to GitHub Pages** 跑绿，**E2E (iPad WebKit)** 也跑绿
- [ ] iPad 是 iPadOS 17 或更新；Safari 打开 `https://<用户名>.github.io/Yoyo-s_Garden/`
- [ ] 分享按钮 →“添加到主屏幕”，之后**只从主屏幕图标打开**（Safari 标签页里是另一份数据）

## 1. 安装与离线

- [ ] 从主屏幕打开是全屏的，顶部没有黄色的“请从主屏幕打开”提醒（在 Safari 标签页里打开时应该有）
- [ ] 完成首次引导后，打开飞行模式，划掉应用再从图标打开：能正常进入，花园和数据都在
- [ ] 冷启动（划掉后重新打开）到看见花园不超过 2 秒

## 2. 横竖屏与触控

- [ ] 横屏：花园、任务、商店、背包、图鉴、家长模式都完整显示，没有被切掉的按钮
- [ ] 竖屏：同样能用（不要求好看，但不能有点不到的东西）
- [ ] 所有按钮手指一点就中，不需要瞄准；PIN 键盘不会误按
- [ ] 双指缩放、双击缩放、页面上下“橡皮筋”回弹都不会出现
- [ ] 装扮：拖拽和“先点物品、再点格子”两种方式都能把家具放下

## 3. 声音

- [ ] 完成任务、金币到账、浇水、长大、收获、买东西、点小动物、唱歌角都有清脆短音
- [ ] 家长模式 → 设置 → 关掉“音效”后，上面这些都不响
- [ ] 运动打卡 60 秒倒计时：“开始！”和“时间到！”的语音和提示音在隔壁房间能听到（这两个不受音效开关影响）
- [ ] iPad 侧边静音开关打开时，记录一下哪些还会响（Safari 网页声音受系统静音影响，属正常）

## 4. 动画

- [ ] 金币从屏幕中间飞进顶部金币栏
- [ ] 花瓣飘落、植物升阶、小动物蹦进来，每个都在 1.5 秒内结束
- [ ] 动画播放时点一下能跳过，不会挡住下一步操作

## 5. 相机与视频（运动破纪录）

- [ ] 运动打卡 → 成绩超过纪录 →“录一段视频”能调起前置相机录像
- [ ] 录完回到应用，输入成绩后进家长待确认；家长模式里能播放、拖动进度条
- [ ] 确认或驳回后视频消失；导出的备份文件里没有视频

## 6. 不可逆操作都有二次确认

- [ ] 铲掉植物、卖果实、卖家具、撤销记录、撤销运动成绩、重置全部数据，都先弹出确认框

## 7. 更新

- [ ] 推送一个新版本后，孩子使用中**不会**自动刷新
- [ ] 进家长模式时顶部出现“有新版本了”，到“设置”里点“更新”后生效

## 8. 备份

- [ ] 家长模式 → 数据 → 导出备份：弹出系统分享面板，能存到“文件”
- [ ] 7 天没备份时，家长模式顶部出现备份提醒
- [ ] 在另一台设备或重置后导入备份：金币、花园、小屋、记录都恢复
